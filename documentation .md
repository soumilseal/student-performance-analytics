## 2. Objective

The objective of this project is to analyze student marks and attendance data using Python, Pandas, and NumPy.

The system calculates student totals, averages, grades, pass/fail results, subject-wise performance, and class-level performance.

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

## 4. Dataset Description

The dataset contains 20 student records.

Each record contains:

- Student ID
- Name
- Department
- Python marks
- SQL marks
- Statistics marks
- Computer Networks marks
- Web Technology marks
- Attendance

The dataset is stored in `students.csv`.

## 5. Implementation

The project is divided into three main files:

### main.py

This is the main program. It reads the student dataset, processes the data, performs calculations, and displays the final analysis.

### functions.py

This file contains reusable functions for:

- Calculating total marks
- Calculating average marks
- Assigning grades
- Checking pass/fail results

### students.csv

This file contains the original student dataset.

## 6. Grading Rule

The following grading system is used:

- 90-100: A+
- 80-89: A
- 70-79: B
- 60-69: C
- 50-59: D
- Below 50: F

## 7. Pass/Fail Rule

A student is considered Pass when:

- The average marks are 50 or above.
- Marks in every subject are 40 or above.

Otherwise, the student is considered Fail.
